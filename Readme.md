# Deviation Games Asteroids IA 
 
Controller for a spaceship in an asteroids game to achieve the highest score.

Rank 10 in https://planetoids21.kattis.com/standings as DKZ'S.

## Setup for Windows
- Download the game by Deviation Games LLC from the latest repository release.
- IMPORTANT: The path of the folder cannot be inside a folder with a space in its name, for example, "ICPC game/", with this, the game cannot be executed.
- Install required prerequisites referred to in the Handout PDF in the System Requirements and Setup sections.
- Copy the IA (py/planetoids.py) from this repository to the same-name file inside the "py" folder in the game.
- Open powershell terminal in the "ICPC" folder.
- Run `.\LaunchGame.bat` to launch the game.
- Run `.\LaunchSubmission.bat` to start the game with AI control.

For other OS, check the "ICPC Game AI Challenge Handout" PDF for setup
